# Evidence directory

Store only sanitized lab evidence here. Never store AWS credentials, session tokens, raw prompts, model completions, production code, real PHI/PII, patient identifiers, personal email addresses, or live account details in Git.

Generated JSON evidence is ignored by Git. Chapter 0 evidence records only check results, a partial account fingerprint, the selected non-production environment and region, and explicit statements that credentials and PHI/PII are absent.
